# Урок 03 — Способы рассуждений

Тот же чат, что в первом уроке, но модель просят думать по-разному: сразу отвечать,
строить цепочку рассуждений, идти по плану, проверять себя. Разница видна на одной
и той же задаче — и по числу токенов, и по правильности ответа.

Стек как в уроках 01–02: FastAPI (порт 8003) + Streamlit (порт 8503), Python, Docker Compose.

```
front (8503) ── переключатель разделов ──┬─▶ chat API   (8000, урок 01)
                                         ├─▶ format API (8002, урок 02)
                                         └─▶ reasoning  (8003, урок 03) ──▶ DeepSeek / mock
```

Фронт урока 03 — общий интерфейс курса: в сайдбаре переключатель
**«Чат (урок 01)» / «Форматы ответа (урок 02)» / «Способы рассуждений (урок 03)»**.
Первый раздел ходит в API урока 01, второй — в API урока 02, третий — в собственный API
этого урока. Адреса задаются переменными `CHAT_API_BASE_URL`, `FORMAT_API_BASE_URL`,
`REASONING_API_BASE_URL`; для уроков 01–02 в compose добавлен `host.docker.internal`,
потому что те стеки живут в отдельных compose-проектах.

## Способы рассуждений

| id | Что просим у модели | Когда полезно |
|---|---|---|
| `direct` | отвечать сразу, без хода мыслей | простые вопросы, экономия токенов |
| `cot` | рассуждать пошагово, итог — после `---` | счёт, логика, «сколько всего» |
| `cot_few_shot` | тот же формат, но по готовому примеру | когда нужно стабильное оформление |
| `plan_solve` | сначала план, потом выполнение по шагам | многошаговые задачи с условиями |
| `self_check` | ответ, затем отдельная проверка и исправление | там, где легко ошибиться в арифметике |

Стратегия — это только system-промпт плюс правило разбора: ответ делится на
«рассуждение» и «итог» по строке `---`. Для `direct` деления нет — весь текст считается ответом.

## UI

- Сайдбар: переключатель раздела, затем выбор модели (popover) и **три фильтра** —
  `Температура`, `Reasoning`, `Max tokens`
  (100…10000, шаг 100). Больше ничего: остальные ручки урока 02 здесь не нужны.
- Вкладка **«Способы рассуждений»**: переключатель стратегии, её system-промпт в раскрывашке
  и окно чата. Ответ модели приходит двумя блоками: «🧠 Рассуждение» (отдельной раскрывашкой)
  и итоговый ответ; в мете — стратегия, модель, температура, reasoning, время и токены.
- Вкладка **«Сравнение стратегий»**: одна задача прогоняется через все стратегии подряд.
  В таблице — токены, время, длина рассуждения, `finish` и сам ответ, ниже — полные тексты.
  Если ответы разошлись, UI так и пишет: «Стратегии разошлись: N разных ответов из 5».
- Reasoning-уровень модели (`none … max`) — это отдельный механизм: встроенные «размышления»
  DeepSeek, которые приходят в `reasoning_content`, а не наш промпт.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | статус, провайдер, число стратегий, прочитанные конфиг-файлы |
| GET | `/api/models` | модели и их возможности (`provider`, уровни reasoning, temperature) |
| GET | `/api/strategies` | стратегии: id, label, описание, system-промпт |
| POST | `/api/chat` | `text/event-stream`: `start` → `reasoning`/`delta` → `result`, либо `error` |
| POST | `/api/compare` | по одному прогону каждой стратегии, JSON-ответ |

Тело `/api/chat`:

```json
{
  "model": "deepseek-flash",
  "messages": [{"role": "user", "content": "5 яблок, 3 груши, 2 апельсина…"}],
  "strategy": "cot",
  "temperature": 0.3,
  "reasoning": "none",
  "max_tokens": 1000
}
```

События:

```
event: start    {"strategy":"cot","strategy_label":"Пошаговые рассуждения (CoT)","model":"deepseek-flash", …}
event: reasoning {"text":"…"}          # reasoning_content модели, если включён reasoning
event: delta    {"text":"шаг 1…"}
event: result   {"strategy":"cot","reasoning_part":"шаг 1…","answer_part":"Ответ: 12 фруктов.",
                 "usage":{"completion_tokens":155},"finish_reason":"stop","truncated":false,
                 "elapsed_ms":2033,"max_tokens":1000}
event: error    {"message":"…","kind":"bad_request"}
```

## Тесты

```bash
docker compose exec api pytest -q      # 16 тестов
```

Покрыто: каталог стратегий, разбор ответа по маркеру (включая `direct` и ответ без `---`),
стриминг чата, подстановка system-промпта стратегии, передача температуры/reasoning/лимита,
потолок `max_tokens` (10000 — ок, 10001 — 422), неизвестная стратегия, ошибка провайдера
событием, сравнение всех стратегий и подмножества.

## Что видно на живой задаче

Задача: «5 яблок, 3 груши, 2 апельсина; два яблока съели, добавили 4 груши — сколько всего?»

| Стратегия | Токенов | Рассуждение | Ответ |
|---|---|---|---|
| Прямой ответ | 4 | — | 10 фруктов ❌ |
| Пошаговые рассуждения (CoT) | 91 | 193 симв. | 12 фруктов ✅ |
| Остальные | — | — | см. вкладку «Сравнение стратегий» |

Вывод урока: «думай по шагам» — не магия, а промпт, который меняет распределение ответов;
на многошаговой арифметике прямой ответ ошибается, а цепочка рассуждений сходится.
Проверять надо оба варианта: CoT тоже иногда ошибается, просто иначе.

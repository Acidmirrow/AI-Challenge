# Урок 10 — Управление контекстом: Сравнение стратегий

Отдельное приложение FastAPI + Streamlit: сравнивает четыре способа собрать
контекст из одного и того же демо-диалога.

## Генерация

При открытии раздела сообщений нет. Кнопка **«Сгенерировать диалог»**
создаёт уникальный диалог: ствол на 25 сообщений и три ветки по 10–15 сообщений с конкретными
деталями в каждом втором сообщении.

## Стратегии

1. **Sliding window** — хранит последние N сообщений; все более старые
   отбрасываются.
2. **Sticky facts / Key-Value memory** — отдельный блок facts «ключ → значение».
   Facts обновляются после каждого сообщения пользователя по последним N
   сообщениям; окно обновления настраивается.
3. **Summary блоки** — ствол сжимается в summary 1–10, 11–20, 21–25;
   к ним добавляется summary выбранной ветки.
4. **Без сжатия — вся история** — в запрос уходит вся история диалога.

## Что реализовано

- API:
  - `GET /api/health`;
  - `GET /api/strategies`;
  - `GET /api/generate` — новый диалог;
  - `POST /api/compare` с параметрами `sliding_window` и `facts_window`.
- Streamlit-страница с выбором стратегии и настройками в сайдбаре;
- выбор ветки в сайдбаре;
- таблица: Стратегия, Деталей сохранено, Токены, Сложность;
- блок выводов по стратегиям;
- отдельный блок фактов для Sticky facts;
- полный диалог: ствол + выбранная ветка;
- Checkpoints в истории диалога;
- сообщения ствола и веток без повторов;
- у каждой ветки отдельные формулировки вопросов;
- переписка до генерации сохраняется и добавляется перед сгенерированным диалогом;
- компактная строка показателей стратегии/токенов/сообщений/facts;
- восемь тестов API.

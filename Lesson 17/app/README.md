# Урок 17 — Первый инструмент MCP

Отдельное FastAPI + Streamlit-приложение: собственный MCP-сервер вокруг
**mock CRM API** и агентский чат, который вызывает MCP-инструмент и использует
полученный результат.

## Что реализовано

1. **Mock API** — `GET /mock/customers/{customer_id}`, `GET /mock/customers`,
   `POST /mock/customers`, `DELETE /mock/customers/{id}`. По умолчанию в CRM
   пять клиентов с разными тарифами, балансами и количеством обращений.
2. **MCP-сервер** `lesson17-crm` по stdio:
   - `get_customer` — карточка клиента (`customer_id`, string, `^C-\d+$`);
   - `list_customers` — все клиенты;
   - `create_customer` — добавление клиента (`name`, `email`, `plan` обязательны);
   - `delete_customer` — удаление клиента по `customer_id`;
   - возврат: JSON с `ok`, `customer` или `customers`.
3. **MCP-клиент** в API урока: `initialize` → `tools/list` → `tools/call`.
4. **Агент**: модель получает схемы инструментов, вызывает нужный инструмент,
   получает наблюдение и использует его в ответе.
5. **UI**:
   - ряд кнопок: «Добавить клиента», «Получить всех клиентов», «Вызвать клиента»,
     «Удалить клиента»;
   - «Добавить клиента» открывает выпадающую форму;
   - «Удалить клиента» выделена красным;
   - чат с агентом;
   - трасса вызова MCP: аргументы и результат.

## Сценарий

```text
Пользователь: Что с клиентом C-104?
Агент: get_customer(customer_id="C-104")
MCP: mock CRM API → карточка клиента
Агент: отвечает по данным карточки
```

## API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/health` | состояние урока |
| `GET` | `/api/lesson` | метаданные реализованного урока |
| `GET` | `/api/models` | модели провайдера |
| `GET` | `/mock/customers/{id}` | карточка клиента |
| `GET` | `/mock/customers` | все клиенты |
| `POST` | `/mock/customers` | добавить клиента |
| `DELETE` | `/mock/customers/{id}` | удалить клиента |
| `POST` | `/api/mcp/inspect` | регистрация инструмента и схема |
| `POST` | `/api/mcp/call` | прямой вызов любого MCP-инструмента |
| `POST` | `/api/chat` | агентский чат с MCP-вызовом |

## Запуск

```bash
cd "Lesson 17/app"
docker compose up -d --build
open http://localhost:8517
curl http://localhost:8017/api/health
```

В общем стеке — `/lesson-17/api/*`; раздел **«Первый инструмент MCP (урок 17)»**
в неделе 4 общего UI.

## Тесты

```bash
docker compose -f "Lesson 17/app/docker-compose.yml" run --rm api python -m pytest -q
```

Тесты проверяют регистрацию четырёх инструментов, входные схемы, прямой вызов,
список, добавление и удаление клиента, ошибку неизвестного клиента и агентские
вызовы. Текущий результат: **10 passed**.

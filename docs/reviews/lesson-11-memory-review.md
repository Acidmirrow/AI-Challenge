## Ограничения и условия

- Нет аутентификации: `owner_id` — учебный идентификатор, не доказательство личности.
- SQLite-файл не зашифрован at-rest; для реальных PII нужен SQLCipher/Postgres с шифрованием и
  управлением ключами.
- Нет эмбеддингов: FTS5 покрывает точные/лексические совпадения, но не семантический поиск.
- Нет автоматического извлечения фактов из диалога: записи создаются явно через UI/API.
- Для production с реальными пользователями статус следует считать **BLOCK** до закрытия
  пунктов аутентификации, шифрования и consent/удаления PII.

## Решение

Для учебного контура урок 11 соответствует R-004–R-013 с указанными ограничениями.
В production-контуре Memory Guardian должен повторить проверку после добавления auth,
шифрования и политики удаления PII.

# AI Challenge — краткое summary уроков

Актуально: уроки 01–07. Это сжатая карта проекта: вместо чтения всех README и
исходников достаточно этого файла, а детали — по ссылкам ниже.

## Архитектура

- Каждый урок — отдельное приложение FastAPI + Streamlit в `Lesson 0X/app/`.
- Общий стек: UI `http://localhost:8500`, шлюз `http://localhost:8000` с
  маршрутами `/lesson-01/api/*` … `/lesson-07/api/*`. Разделы UI сгруппированы
  по 5 уроков: 01–05 — неделя 1, 06–07 — неделя 2; стартует последний урок.
- Общий фронт собирается из `Lesson 06/app/front`; изолированные порты:
  01 → 8000/8501, 02 → 8002/8502, 03 → 8003/8503, 04 → 8004/8504,
  05 → 8005/8505, 06 → 8006/8506, 07 → 8007/8507.
- Провайдеры: DeepSeek (основной), бесплатные OpenRouter и Nous Portal; Gemini есть в API, но скрыт во фронте.
  Ключи — в gitignored `Lesson 0X/app/config/secrets.properties`.
- Уроки 01–07 используют общий выбор модели в сайдбаре; бесплатные модели
  фильтруются по `:free` и стоимости 0.

## Урок 06 подробнее

- Инструменты: `calculator`, `current_time`, `text_stats`, `currency_rates`,
  `unit_converter`, `date_diff`, `number_base`, `number_stats`, `text_hash`.
- `currency_rates` — курсы через открытый `open.er-api.com` (без ключа, кеш 10 минут).
- Остальные новые инструменты локальные и детерминированные: единицы, даты,
  системы счисления, статистика чисел, SHA-256/SHA-1/MD5.
- В сайдбаре можно выбрать любое подмножество инструментов, включая пустое;
  при нехватке нужного инструмента агент отвечает «нет возможности ответить»,
  а не выдумывает результат.
- API: `POST /api/agent`, `GET /api/tools`, `GET /api/models`, `GET /api/health`.
- Код: `Lesson 06/app/api/app/agent.py` (класс `Agent`), `agent_tools.py`
  (`ToolRegistry`); UI — `front/agent_page.py`.

## Урок 07 подробнее

- Контекст хранится в SQLite `Lesson 07/app/data/context.db`; таблицы `sessions`
  и `messages`. В истории сохраняются реплики, `tool_calls`, имена инструментов
  и наблюдения `role=tool`.
- После очистки пустая сессия не считается диалогом; счётчик показывает только
  диалоги с сообщениями.
- В сайдбаре есть удаление всех контекстов из SQLite (с подтверждением).
- При открытии раздела загружается последняя обновлённая сессия со всей историей.
- Сессии выбираются из выпадающего списка: «Диалог N · тема · сообщений»;
  номер обеспечивает уникальность, ID хранится в URL (`?session=...`).
- `session_id` хранится в URL (`?session=...`), поэтому после перезагрузки
  страницы открывается тот же диалог; в сайдбаре можно создать новую сессию,
  очистить историю или удалить её.
- Перед запросом API собирает окно из последних сообщений (2–500 в UI, по
  умолчанию 20) и ограничивает его 20 000 символов; старые сообщения отбрасываются.
- В сайдбаре можно отметить несколько прошлых бесед или включить «Все прошлые
  сессии»: их сообщения и tool calls подмешиваются в контекст текущего запроса.
  Если в запросе явно указано «Диалог N», его история подключается автоматически;
  фраза «из разных сессий» подключает весь архив.
- API: `POST /api/chat`, `GET /api/tools`, `GET /api/sessions`,
  `GET /api/sessions/{id}`, `DELETE /api/sessions` (все),
  `DELETE /api/sessions/{id}` (одна), `POST /api/sessions/{id}/clear`.
- Инструменты — те же 9, что в уроке 06 (`agent_tools.py`); агент продолжает
  диалог с загруженной историей, включая прошлые вызовы инструментов.
- UI: вверху справа компактные показатели (сообщения, сессия, модель,
  диалоги), сообщения compact, метки «💾 сохранено», итог с действиями.
- Код: `Lesson 07/app/api/app/storage.py`, `context.py`, `agent.py`; UI —
  `Lesson 07/app/front/context_page.py`.

## Ключевые решения

- Общая архитектура «урок = приложение»: копипаста между уроками осознанная,
  общий стек только собирает их за одним адресом.
- Все секреты — только в gitignored properties/`.env`; в git едут `*.example`.
- Nous Portal подключается напрямую по ключу или через локальный `hermes proxy`
  (loopback + `Host`-заголовок); бесплатны только модели с `:free`.
- В уроке 06 проверка нехватки инструмента детерминированная (по типу задачи),
  плюс страховка, если модель сама попросит недоступный инструмент.

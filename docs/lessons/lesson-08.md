# Урок 08 — работа с токенами

Отдельное приложение курса: FastAPI + Streamlit. Урок показывает, как текст
занимает контекстное окно модели, сколько остаётся под ответ и как обрезать
историю по границе токена.

## Что показывает

- символы, слова и оценку токенов;
- отношение токенов к словам и символам;
- контекстное окно выбранной модели и резерв под ответ;
- помещается ли текст, сколько копий текста влезет в окно;
- превышение и вариант текста, обрезанный до доступного бюджета;
- предпросмотр первых 120 токенов;
- стоимость входа по фактически помещающимся токенам и максимального резерва ответа;
- сравнение трёх контекстов: минимальный, большой в пределах демо-окна и
  максимальный с превышением, с выводами о зависимостях;
- рост prompt-токенов и стоимости по ходам диалога и последствия переполнения.

Токенизация учебная: слова и знаки пунктуации считаются отдельными единицами.
Реальный BPE-токенизатор модели может дать другое число; точный расход виден
в `usage` ответа модели.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | статус и число моделей |
| GET | `/api/models` | модели и размеры контекста |
| GET | `/api/presets` | готовые тексты для примеров |
| POST | `/api/analyze` | токены, бюджет и обрезка |
| POST | `/api/dialogue` | рост prompt-токенов и стоимости по ходам |
| POST | `/api/truncate` | обрезать текст до N токенов |

`POST /api/analyze` принимает `text`, `model`, `output_reserve`; `POST /api/dialogue` — параметры симуляции диалога. В ответе:
`chars`, `words`, `tokens`, `tokens_per_word`, `available`, `fits`, `copies`,
`overflow`, `preview`, `truncated_text`.

## Запуск

В общем стеке:

```bash
docker compose up -d --build
open http://localhost:8500        # «Работа с токенами (урок 08)»
```

Изолированно:

```bash
cd "Lesson 08/app"
docker compose up -d --build      # UI :8508, API :8008
```

## Тесты

```bash
cd "Lesson 08/app"
docker compose run --rm api python -m pytest -q
```

15 тестов: токенизатор, статистика, бюджет, стоимость, сравнение контекстов, рост диалога, обрезка и API.

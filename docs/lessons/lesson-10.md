# Урок 10 — Управление контекстом: Сравнение стратегий

Отдельное приложение FastAPI + Streamlit: сравнивает четыре стратегии на одном
демо-диалоге: общий ствол на 25 сообщений и три ветки по 10–15 сообщений, начинающиеся после №25.

## Генерация диалога

При открытии раздела сообщений нет. Кнопка **«Сгенерировать диалог»**
создаёт новый диалог: 25 общих сообщений и три ветки по 10–15 сообщений; каждый второй ответ
содержит конкретные детали — сроки, бюджеты, ограничения, имена, решения,
названия и параметры. Код и значения уникальны для каждой генерации.

## Стратегии

1. **Sliding window** — последние N сообщений; всё, что старше, отбрасывается.
2. **Sticky facts / Key-Value memory** — отдельный блок facts «ключ → значение».
   Facts обновляются после каждого сообщения пользователя по последним N
   сообщениям; окно обновления задаётся в сайдбаре.
3. **Summary блоки** — ствол сжимается в summary 1–10, 11–20, 21–25, к ним добавляется summary выбранной ветки.
4. **Без сжатия — вся история** — в запрос уходит вся история.

## Что реализовано

- sidebar: выбор стратегии без текстового ввода и кнопка «Очистить весь диалог»;
- для Sliding window — управление N;
- для Sticky facts — управление числом последних сообщений, участвующих
  в обновлении facts;
- окно чата с ИИ-моделью и отправка вопросов по текущему контексту;
- переключатель «Только по контексту»: включён — ответ по выбранной стратегии, выключен — общий вопрос к модели;
  до генерации ответы идут через реальную модель `deepseek-flash` (при недоступности — локальный fallback);
- сообщение в пустом чате не создаёт диалог; полная генерация — только по кнопке;
  переписка до генерации сохраняется и добавляется перед сгенерированными сообщениями;
- блок facts с ключами и значениями;
- при любой стратегии отображается полный диалог: ствол + выбранная ветка;
- Checkpoints: старт, 10, 20, точка ветвления №25, начало и конец каждой ветки;
- сообщения ствола и веток уникальны — повторяющихся реплик нет;
- формулировки вопросов ствола и каждой ветки различаются по смыслу и явно привязаны к ветке;
- в сайдбаре выбирается одна из трёх веток; сравнение пересчитывается для неё;
- Sliding window автоматически получает 10 сообщений ствола + всю выбранную ветку;
- строка со стратегией, токенами, сообщениями и facts оформлена мелким шрифтом;
- служебный код проекта не отображается во фронте;
- таблица: Стратегия — Деталей сохранено — Токены — Сложность;
- после таблицы — развёрнутый вывод по каждому сценарию от `deepseek-v4-pro`.
- API:
  - `GET /api/health`;
  - `GET /api/strategies`;
  - `GET /api/generate` — новый диалог;
  - `POST /api/compare`;
  - `POST /api/ask` — ответ по выбранной стратегии;
  - `POST /api/chat` — свободный ответ модели без создания диалога.
- тесты: 8.

## Запуск

В общем стеке раздел открывается на `http://localhost:8500`; API доступен по
`http://localhost:8000/lesson-10/api/...`.

Изолированно:

```bash
cd "Lesson 10/app"
docker compose up -d --build
```

- API: `http://localhost:8010`
- UI: `http://localhost:8510`

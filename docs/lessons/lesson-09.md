# Урок 09 — управление контекстом

Отдельное приложение FastAPI + Streamlit: показывает, как из длинного диалога
выбирается часть сообщений, которая реально уйдёт модели, и как полную историю
можно заменить отдельно хранимыми summary.

## Что делает урок

- формирует демонстрационный диалог из **25 сообщений** (12 пар и завершающая
  реплика) по кнопке **«Сформировать диалог»** в сайдбаре;
- диалог разбит на **3 summary-блока**: 10, 10 и 5 сообщений; summary
  хранятся отдельно и не являются сообщениями;
- в диалоге есть вымышленные, но конкретные данные: адрес, суммы, сроки,
  площадь, этажность, инженерные параметры, подрядчик и штрафы;
- в блоке **«Управление контекстом»** можно выбрать:
  - стратегию из выпадающего списка без текстового ввода: «Бюджет токенов»,
    «Последние N сообщений», «Вся история»; под каждым вариантом есть подсказка;
  - лимит сообщений;
  - размер окна контекста;
  - резерв токенов под ответ;
- для каждого сообщения видно, попало оно в контекст (`✅ в контексте`) или
  отброшено (`⛔ отброшено`);
- сверху показываются сообщения, размер контекста, число отброшенных и
  предупреждение о переполнении;
- диалог не кэшируется в UI: при каждом перерасчёте он заново запрашивается
  из API, а вопрос каждый раз отправляется с заново собранным контекстом;
- внизу есть чат по истории: ответ ищется только среди сообщений, попавших в
  текущий контекст, и показывает источник (`№`); если факт отброшен, ответ
  объясняет, какие сообщения попали в контекст и какие были отброшены;
- кнопка **«Сжать контекст»** заменяет полную историю на 3 summary; повторное
  нажатие возвращает полные сообщения;
- вкладка **«Сравнение токенов»** отделена от диалога: таблица показывает
  сообщения, summary, токены до и после сжатия, экономию и попадание в окно.

## Демо-диалог

Проект «Ласточка» — вымышленный объект:

- адрес: Москва, ул. Лесная, 14, корпус 2;
- бюджет: 4 850 000 ₽, оплата 30/40/30;
- площадь: 320 м², 3 этажа, 18 окон, 2 лифта, потолки 3,2 м;
- срок сдачи: 31 марта 2027 года;
- этапы: 15.12.2026, 01.02.2027, 15.03.2027;
- подрядчик: ООО «СтройКонтур», контакт — Ирина Соколова;
- резерв на риски: 250 000 ₽.

3 summary покрывают диапазоны 1–10, 11–20 и 21–25.

Все совпадения случайны; данные нужны только для проверки контекста.

## Стратегии

| Стратегия | Что делает |
|---|---|
| `budget` | идёт от последних сообщений к старым и набирает их, пока хватает токенов и лимита сообщений |
| `last` | берёт ровно последние N сообщений; окно токенов показывает, помещаются ли они |
| `full` | отправляет всю историю; удобно увидеть переполнение |

`available` — бюджет после вычета резерва под ответ. `message_budget` —
сколько из него остаётся на сообщения после системной части (20 токенов).
Если сообщения не помещаются, API возвращает `overflow` и `fits=false`.

## API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/health` | статус и число демо-сообщений |
| `GET` | `/api/demo-dialogue` | 25 демо-сообщений и 3 summary |
| `POST` | `/api/context` | выбор сообщений и статистика контекста |
| `POST` | `/api/ask` | ответ на вопрос только по выбранным сообщениям/summary; `found` показывает, найден ли источник |
| `POST` | `/api/compress` | сравнение токенов полной истории и отдельного набора summary |

Пример:

```bash
curl -s http://localhost:8000/lesson-09/api/demo-dialogue
curl -s -X POST http://localhost:8000/lesson-09/api/context \
  -H 'Content-Type: application/json' \
  -d '{"messages":[],"strategy":"budget","max_messages":12,"max_tokens":4000,"reserve_tokens":500}'
```

## Запуск

В общем стеке:

```bash
docker compose up -d --build
open http://localhost:8500
```

Изолированно:

```bash
cd "Lesson 09/app"
docker compose up -d --build
open http://localhost:8509
```

Порты: API `8009`, UI `8509`; в общем стеке — префикс
`http://localhost:8000/lesson-09/api/...`.

## Ограничения

- Токенизация — учебная regex-аппроксимация, как в уроке 08; точный расход
  виден в `usage` реального ответа модели.
- Демо-диалог и чат по истории не вызывают внешнюю модель: это заранее
  подготовленный сценарий и детерминированный поиск по контексту, чтобы
  одинаково проверять стратегии и видеть, когда факт отброшен.
- Summary подготовлены вместе с демо-диалогом и хранятся отдельным списком;
  это не автоматическая LLM-суммаризация, а воспроизводимый учебный пример.
- Урок не сохраняет диалог в базу: история живёт в состоянии Streamlit-сессии.

## Тесты

18 тестов: 25 сообщений и 3 summary, покрытие блоков 10/10/5,
три стратегии, лимит сообщений, бюджет, сжатие и сравнение токенов, API,
чат по истории, отсутствие факта в контексте и граничные случаи.

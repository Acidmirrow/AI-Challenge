# Урок 07 — сохранение контекста

Отдельное приложение курса: FastAPI + Streamlit. Диалог сохраняется в SQLite
вместе с вызовами инструментов, поэтому история не теряется при перезагрузке
страницы, перезапуске API или контейнера.

## Что показывает урок

- у каждого диалога есть `session_id`; он хранится в URL (`?session=...`);
- каждый ход «пользователь → ассистент» пишется в SQLite;
- в историю попадают `tool_calls`, имена инструментов и наблюдения `role=tool`;
- используются те же 9 инструментов, что в уроке 06;
- выбор инструментов — такой же поповер с чекбоксами 0–9, как в уроке 06;
- можно отметить несколько прошлых бесед или включить «Все прошлые сессии»:
  их реплики и tool calls добавляются в контекст;
- если в запросе указано «Диалог N», его история подключается автоматически;
  фраза «из разных сессий» подключает весь архив;
- в истории UI видны только факты вызова и человекочитаемые действия, без JSON
  аргументов и ответов инструментов; каждая сохранённая реплика/результат
  отмечена «💾 сохранено в контексте»;
- внизу — «Итог» с результатом, действиями и перечнем использованных инструментов;
- перед запросом API собирает окно из последних сообщений;
- окно ограничено числом сообщений (в UI 2–500, по умолчанию 20) и общим лимитом символов;
- при переполнении старые сообщения отбрасываются, но новый вопрос сохраняется;
- историю можно очистить, удалить одну сессию или все контексты сразу;
- после очистки пустая сессия не считается диалогом в счётчике базы.

```
SQLite (data/context.db)
  sessions: id, title, created_at, updated_at
  messages: id, session_id, role, content, tokens, created_at,
            tool_calls, tool_call_id, name
        │
        ▼
GET /api/sessions/{id}  ──►  UI: история диалога
POST /api/chat          ──►  окно контекста → LLM → сохранение пары сообщений
```

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | статус, путь к SQLite, число сессий |
| GET | `/api/models` | каталог моделей |
| GET | `/api/tools` | 9 инструментов из урока 06 |
| GET | `/api/providers/status` | доступность провайдеров |
| GET | `/api/sessions` | список сохранённых диалогов |
| GET | `/api/sessions/{id}` | сессия и все сообщения |
| DELETE | `/api/sessions` | удалить все диалоги и сообщения |
| DELETE | `/api/sessions/{id}` | удалить один диалог |
| POST | `/api/sessions/{id}/clear` | очистить историю, оставить сессию |
| POST | `/api/chat` | один ход диалога с сохранением контекста |

`POST /api/chat` принимает `session_id`, `prompt`, `model`, `temperature`,
`reasoning`, `max_tokens`, `max_messages`, `max_steps`, `tools` (None — все,
[] — ни одного) и `context_sessions` — список прошлых диалогов для контекста.
В ответе есть `answer`, полная `messages` с tool calls, `steps` текущего хода,
статистика `context` и `usage`.

## Запуск

В общем стеке:

```bash
docker compose up -d --build
open http://localhost:8500        # «Сохранение контекста (урок 07)»
```

Изолированно:

```bash
cd "Lesson 07/app"
docker compose up -d --build      # UI :8507, API :8007
```

Секреты: скопируйте `config/secrets.properties.example` в
`config/secrets.properties` и заполните ключ провайдера. Файл gitignored.
Без ключа доступна офлайн-модель `mock-fast`.

## Тесты

```bash
cd "Lesson 07/app"
docker compose run --rm api python -m pytest -q
```

21 тест: API, SQLite-хранилище, сохранение tool calls, выбор прошлых бесед, автоподключение «Диалог N», удаление всех контекстов и сборка окна контекста.

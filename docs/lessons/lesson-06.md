# Урок 06 — ИИ-агент

Модель получает задачу и набор инструментов, сама решает, что вызвать, сервер
выполняет функцию и возвращает наблюдение обратно в диалог. Цикл повторяется до
финального ответа или лимита шагов; UI показывает итог, а полную трассу с
аргументами и результатами инструментов прячет в свёрнутый блок.

```
UI:  http://localhost:8506     # изолированный запуск
API: http://localhost:8006     # /api/health, /api/agent, /api/tools
```

В общем стеке курс открывается на `http://localhost:8500`, раздел
**«ИИ-агент (урок 06)»**, API — `http://localhost:8000/lesson-06/api/*`.

## Что умеет агент

| Инструмент | Что делает | Пример задачи |
|---|---|---|
| `calculator` | безопасно считает арифметику: `+ - * / // % **`, скобки, `round/abs/min/max` | «Посчитай 17% от 4 850» |
| `current_time` | дата, время, день недели в часовом поясе IANA | «Сколько сейчас времени в Москве?» |
| `text_stats` | символы, слова, предложения, строки, время чтения | «Сколько слов в тексте …?» |
| `currency_rates` | курсы валют по открытому API open.er-api.com | «Какой курс доллара к рублю?» |
| `unit_converter` | длина, масса, температура, объём, данные, время | «Переведи 5 км в метры» |
| `date_diff` | разница дат и прибавление дней | «Сколько дней между 2026-01-01 и 2026-11-09?» |
| `number_base` | перевод между системами счисления 2–36 | «Переведи 255 в шестнадцатеричную» |
| `number_stats` | среднее, медиана, минимум/максимум, размах, отклонение | «Статистика чисел 2, 4, 6» |
| `text_hash` | SHA-256 / SHA-1 / MD5 текста | «Посчитай SHA256 от hello» |

Инструменты — обычные Python-функции с JSON-схемами в формате OpenAI tools.
Калькулятор не использует `eval`: разбирается AST и разрешены только числа,
арифметические операции и четыре безопасные функции.

## Выбор инструментов и отказ

В сайдбаре можно выбрать любое подмножество инструментов, включая пустое.
Если для задачи нужен инструмент, которого нет в выбранном наборе, агент не
пытается ответить по памяти, а пишет: «У ИИ-агента нет возможности ответить
на этот вопрос: нужен инструмент … но он не выбран». Это проверяется до вызова
модели по ключевым словам задачи, а также если модель всё же попросит
недоступный инструмент.

## Цикл агента

```
задача → модель выбирает инструмент → сервер выполняет → наблюдение
      → модель решает: ещё инструмент или итог → ответ
```

В коде это класс `Agent` (`agent.py`) с собственным состоянием: сообщения,
шаги, usage, `reset()` и `run()`. Инструменты передаются агенту через
`ToolRegistry` (`agent_tools.py`), а HTTP-эндпоинт только создаёт агента и
вызывает `run()`.

- один шаг — один вызов инструмента; модель не может вызвать два за раз;
- после каждого наблюдения диалог дополняется сообщениями `assistant.tool_calls`
  и `tool`, поэтому модель видит, что уже было сделано;
- `max_steps` (1–10, по умолчанию 10) защищает от зацикливания; если лимит
  исчерпан, модель получает просьбу подвести итог уже без инструментов;
- если провайдер не поддерживает function calling, API один раз повторяет запрос
  без инструментов и возвращает обычный ответ — урок не падает на такой модели.

## API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/health` | статус, провайдер, число инструментов |
| `GET` | `/api/models` | каталог моделей с провайдерами и reasoning-уровнями |
| `GET` | `/api/providers/status` | доступность провайдеров (кеш на минуту) |
| `POST` | `/api/models/refresh` | перечитать бесплатные модели провайдеров |
| `GET` | `/api/tools` | схемы и подписи инструментов для UI |
| `POST` | `/api/agent` | запустить агентский цикл и вернуть ответ + шаги |

Пример:

```bash
curl -s http://localhost:8006/api/agent \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"Посчитай 17 * 4","model":"deepseek-flash","max_steps":4}'
```

Ответ содержит `answer`, `steps[]` (инструмент, аргументы, наблюдение, время),
`usage`, `elapsed_ms`, `stopped_reason` и стоимость прогона.

## Интерфейс

В сайдбаре сверху — переключатель недель в одну строку: «Неделя 1» / «Неделя 2».
Ниже показываются только уроки выбранной недели: 01–05 или 06. По умолчанию
открывается последний урок. Уроки — минималистичные строки с индикатором ●/○
без кнопочных рамок. Ниже — верхний выбор модели (как в
остальных уроках), температура, max tokens, reasoning, «Максимум шагов» и
чекбоксы инструментов в выпадающем списке: можно отметить от нуля до всех сразу. На странице:

- поле своей задачи, кнопка «Вставить пример» (пример на все 9 инструментов)
  и кнопка «Запустить агента»;
- ответ и метрики (шаги, время, токены, стоимость);
- полная трасса шагов с аргументами и наблюдениями — в свёрнутом блоке
  «Полные размышления и вызовы инструментов»;
- под трассой — короткий список вызванных инструментов с порядком и числом повторов;
- предупреждения при лимите шагов, обрыве по `max_tokens` и нехватке инструмента.

## Конфигурация

`config/app.properties` — провайдер, base_url, reasoning/token-параметры,
`pricing.file`. Секреты — в gitignored `config/secrets.properties`
(`deepseek.api.key`, `gemini.api.key`, `openrouter.api.key`, `nous.api.key`).
Образец — `config/secrets.properties.example`. Gemini поддерживается API,
но во фронте скрыт: его модели и индикатор провайдера не показываются.

## Изолированный запуск

```bash
cd "Lesson 06/app"

```

## Тесты

60 тестов: безопасность калькулятора (включая деление на ноль и запрещённые
конструкции), статистика текста, курсы валют с подменённым источником, единицы,
даты, системы счисления, статистика чисел, хеши, часовые пояса, каталог из девяти
инструментов, выбор подмножества, отказ при невыбранном инструменте, валидация
запроса и агентский цикл на scripted-провайдере — несколько инструментов подряд,
лимит шагов, битые аргументы и суммирование usage.

## Ограничения

- Качество выбора инструментов зависит от модели: маленькие бесплатные модели
  могут отвечать без вызова инструмента или ошибаться в аргументах.
- Курсы валют приходят с открытого API open.er-api.com (без ключа, кеш 10 минут) и могут
  быть недоступны без интернета; в этом случае инструмент возвращает ошибку, а агент
  не выдумывает курс.
- Потолок ответа — 10 000 токенов; при обрыве UI показывает предупреждение.
